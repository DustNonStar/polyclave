# Phase 1A v5 migration and Phase 1B test ownership

Line numbers refer to the unchanged `legacy-node/tests/` archive on this branch. The Rust entries below are evidence for the named assertions, not a claim that the archive was mechanically translated. Legacy runtime tests stay in the archive. Do not remove the archive until the Phase 1B owner cases pass and removal is approved.

A valid staged push with no receipt enters review, not retryable. Malformed but readable evidence reports the **actual** tip; an unreadable mirror interrupts and must be rechecked before retry.
